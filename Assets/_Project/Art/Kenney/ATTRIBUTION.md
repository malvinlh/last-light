# Third-party art

All visual assets in this folder are by **Kenney** (<https://kenney.nl>) and released under
**Creative Commons CC0 1.0 Universal** — public domain. No attribution is legally required;
it is given here because crediting the people whose work you ship is the decent thing to do.

| `UI/panelInset_beige.png` | UI Pack: RPG Expansion |

Only the files actually used are committed, rather than the full packs, to keep the repository
small. The original `LICENSE.txt` from each pack is kept alongside its files.

The neutral grey and light variants were chosen deliberately: this game's palette is dark, and
multiplying a near-white sprite by a tint reproduces the intended colour faithfully, whereas
tinting the beige or brown variants muddies everything.

**Everything else is original.** All gameplay code is mine, and `Art/Generated/Actor_Disc.png` is
produced by the scene builder at edit time rather than authored by hand.
